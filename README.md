# 🎓 Student Management System - Laravel

## 📌 Overview

The **Student Management System** is a web-based application developed using the Laravel framework. It aims to streamline the management of student information, including enrollment, cand more, providing an efficient solution for educational institutions.

## 🛠️ Features

- 🏫 **Student Enrollment and Teachers Management**
- 📚 **Course Management**
- 💰 **Payment Management**
- 🖨️ **Payment Receipt Print**

## 🏗️ Tech Stack

- **Frontend**: HTML, Bootstrap CSS
- **Backend**: Laravel Framework 
- **Database**: MySQL

## 🚀 Installation

Follow these steps to set up the project locally:

### **Step 1: Clone the Repository**
```sh
git clone https://github.com/NipunSachintha-NS/Student-Management-System-Laravel.git
cd Student-Management-System-Laravel
```

### **Step 2: Install Dependencies**
```sh
composer install
npm install
```

### **Step 3: Environment Configuration**
- Duplicate the `.env.example` file and rename it to `.env`.
- Update the `.env` file with database credentials and other necessary configurations.

### **Step 4: Generate Application Key**
```sh
php artisan key:generate
```

### **Step 5: Run Migrations and Seeders**
```sh
php artisan migrate --seed
```

### **Step 7: Start the Development Server**
```sh
php artisan serve
```
